# Pony Pinball Tower

JS13k game entry for 2026.

In this game your challenge is to get the ball to the top of the tower utilizing the flippers, launchers, and conveyer belts to bypass the many obstacles in your way.

Controls: Left/Right and Spacebar

# Dev Notes

Building the final zip:

```
npm run build
```

Testing the build
```
npm run dist
```

This repo includes an editor that writes the source file for the primary level.  It lives in editor and is run with

```
cd editor
npm run start
```
